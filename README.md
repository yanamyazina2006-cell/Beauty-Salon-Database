# База данных сети салонов красоты

**Pet-проект · Системный аналитик**

## О проекте
Реляционная база данных для автоматизации сети салонов красоты: учёт клиентов, сотрудников, услуг, записей и платежей.

## Что сделано
- 12 сущностей, концептуальная и даталогическая ER-модели (IDEF1X)
- Словарь данных: атрибуты, типы, ограничения
- SQL: DDL, SELECT (CROSS JOIN, INNER JOIN, LEFT JOIN, GROUP BY/HAVING, CASE, подзапрос), VIEW
- Триггеры и хранимые процедуры в MySQL
